About SentinelAI

SentinelAI is a personal AI-powered Cyber Threat Intelligence platform. I built it to simplify the process of gathering and understanding cybersecurity threats. By automating the collection of CVEs and security news, SentinelAI makes threat intelligence more accessible and actionable for everyone.

Core Capabilities

  • Aggregates cybersecurity news and latest vulnerabilities (CVEs).
  • Generates AI-driven summaries of complex threat data.
  • Stores intelligence data for historical analysis.
  • Sends automated security alerts and reports.

Built With

  • Python
  • FastAPI
  • SQLite
  • AI / LLMs
  • APScheduler
  • Telegram Alerts
  • HTML / CSS / JS

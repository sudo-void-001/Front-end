# SentinelAI - Frontend Starter Website

A minimal, professional, multi-page frontend website built for **SentinelAI**, a personal AI-powered Cyber Threat Intelligence platform. This project serves as a clean, responsive starter UI showcasing the platform's core capabilities.

## Features

- **3 Linked Pages:** Home, About, and Contact.
- **Responsive Design:** Optimized for both desktop and mobile views.
- **Cybersecurity Aesthetic:** Clean, developer-focused, and minimal interface.
- **Client-Side Validation:** A simple, functional contact form with JavaScript validation (no backend).

## Tech Stack

- HTML5 (Semantic Structure)
- CSS3 (Custom Variables, CSS Grid, Flexbox)
- Vanilla JavaScript (Form Validation)
- *No external frameworks or libraries.*

## Learning Outcomes

- Structuring semantic HTML for improved accessibility and SEO.
- Styling multi-page websites cleanly using CSS Variables and Flexbox/Grid.
- Building a responsive layout with media queries without relying on UI libraries like Bootstrap or Tailwind.
- Implementing basic client-side form validation using Vanilla JavaScript.
- Understanding the fundamentals of linking and navigating across standard HTML pages.

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in any modern web browser to view the live site.
3. Use the navigation links in the header or footer to browse between pages.

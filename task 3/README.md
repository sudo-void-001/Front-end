# BEGINNER Task 3 – JavaScript Interaction Web Page

**Theme:** Cryptonite — Explore Steganography  
**Repo:** [github.com/sudo-void-001/Cryptonite](https://github.com/sudo-void-001/Cryptonite)

## 🎯 Learning Outcomes

| Concept | Usage |
|---|---|
| `querySelector()` / `querySelectorAll()` | Select DOM elements |
| `addEventListener()` | Attach click, submit, scroll, mousedown events |
| `classList.toggle/add/remove()` | Control accordion, modal, validation states |
| `preventDefault()` | Stop form from reloading the page |
| `IntersectionObserver` | Trigger scroll-reveal animations |
| Basic email regex | Client-side form validation |

## 🚀 Features
- **Side-Scrolling Image Gallery** — Drag-to-scroll cards with generated illustrations
- **FAQ Accordion** — Click to expand/collapse with smooth animation
- **Info Modal** — Conceptual steganography explainer popup
- **Contact Form** — Client-side validation with error/success states
- **Scroll Progress Ring** — SVG ring that fills as you scroll, doubles as back-to-top
- **Typewriter Effect** — Human-like randomized typing speed on the hero title
- **Scroll Reveal** — Staggered fade-in animations via IntersectionObserver
- **No Frameworks** — Pure HTML, CSS, JS
- **Fully Responsive** — Desktop, tablet, mobile

# ATELIER - Service Booking Web Experience

## Overview
A premium, understated service-booking web experience for a fictional creative studio called ATELIER. Built for the SAN WebTechnology Front-End Internship — Advanced Task 1.

## Features
- **Service selection:** Dynamic rendering of services with a focused UI.
- **Date & Time selection:** Practical upcoming-date selector.
- **Customer details:** Concise form with inline validation.
- **Booking review:** Summary of selected options with edit capabilities.
- **Confirmation state:** Graceful success screen with a generated reference number.
- **localStorage persistence:** Draft booking state survives page refreshes and navigation.
- **Responsive UI:** Adapts gracefully from desktop (max 1200px) down to mobile (375px).

## Technologies
- HTML5 (Semantic Structure)
- CSS3 (Custom Properties, Grid, Flexbox)
- Vanilla JavaScript (DOM manipulation, localStorage)
- No frameworks or libraries. No backend.

## User Flow
1. **Service** (`index.html`): Choose a session.
2. **Date & Time** (`booking.html`): Find an available slot.
3. **Details** (`booking.html`): Enter name, email, phone, and optional note.
4. **Review** (`booking.html`): Check details and confirm.
5. **Confirmation** (`confirmation.html`): Booking success and reference.

## Learning Outcomes
This project demonstrates:
- Multi-page frontend architecture
- DOM manipulation and dynamic rendering
- JavaScript state management via localStorage
- Form validation
- Event handling
- Progressive disclosure UI patterns
- Responsive UI design principles
